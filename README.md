# YOLO-RD

A research implementation of a custom YOLO-based object detection model, designed for real-time detection and optimized training. This repository contains the model code, training scripts, and experiment configurations — with external data and weights hosted separately.

---

## 🚀 Features

- Custom YOLO architecture: `rd-9c.yaml`
- Lightweight and scalable
- Supports LLM/VLM/GPT-2-based initialization
- Training-ready with custom datasets
- Clean and efficient folder structure
